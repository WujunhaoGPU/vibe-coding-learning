## Week 1 的核心问题

- 为什么直接 prompt → code 容易失控？
- 为什么探索、计划与执行需要分离？
- AI 越强，人还应该保留哪些判断？
- 测试、验证和上下文管理为什么会变得更重要？
- 如何把这些方法迁移到真实项目，而不是只停留在“技巧”层面？

## 建议学习方式

带着问题读原文 → 看中文学习版校准理解 → 合上材料自己复述 → 让 DeepTutor 追问 / 出 Quiz → 映射到真实项目 → 写下“我准备改变什么”。

不要把“读完三篇文章”当作完成标准。完成标准是：你能不用看资料，解释三位作者为什么都在反对“直接生成、直接接受”的工作方式，并能指出你自己的工程流程中对应的问题。
